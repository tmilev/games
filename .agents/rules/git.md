# Git & Commit Rules

## Agent Commit Message Format

Unless the user explicitly requests otherwise, **all git commits authored or created by an AI agent must begin with the UTF-8 sparkles symbol (`✨`) followed by the model name and a colon**, like this:

```text
✨Gemini: <Brief summary of changes>

- <Detailed change item 1>
- <Detailed change item 2>
```

### Examples:
- `✨Gemini: Fix card stack drag preview and boundary clipping`
- `✨Gemini: Add zoom in/out controls with localStorage persistence`
