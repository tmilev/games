# Git & Commit Rules

## Agent Commit Message Format

Unless the user explicitly requests otherwise, **all git commits authored or created by an AI agent must begin with the UTF-8 sparkles symbol (`✨`) followed by the model family and flavor (e.g. `Flash`, `Pro`) and a colon**, like this:

```text
✨Gemini Flash: <Brief summary of changes>

- <Detailed change item 1>
- <Detailed change item 2>
```

### Examples:
- `✨Gemini Flash: Fix card stack drag preview and boundary clipping`
- `✨Gemini Pro: Refactor solver algorithm and state tree traversal`
